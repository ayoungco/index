# index documentation

This directory is arranged around the decisions needed to build, operate, and
extend index. Start with the product model, then use the roadmap only to choose
the next experiment.

| Document | Use it for |
| --- | --- |
| [Product model](product.md) | What index is, its users, identity model, and core workflows. |
| [Architecture](design.md) | Current application structure and technical boundaries. |
| [Operations](operations.md) | Auth, uploads, privacy, camera, location, and delivery practices. |
| [Roadmap](roadmap.md) | Deliberately sequenced product and architecture bets. |
| [Decision log](decisions.md) | Decisions that constrain future work. |
| [Wikidata MVP](story/78-wikidata-integration.md) | The narrower integration backlog. |

`context/` is an archive of source material and retired UI explorations. It is
not a source of current product requirements; see [its index](context/README.md)
before using anything from it.
